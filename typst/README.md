# 408 试题册与答题纸

用 Typst 0.15.1 生成 A4 黑白试题册和独立答题纸。试题册含封面、考生信息栏、40 道单项选择题和 7 道综合应用题；选择题尽量整题同页，选项按实际宽度采用四列、两列或一列。答题纸共 8 页：一页选择题填涂区和七页综合题答题区。

## 构建

先安装 uv、Typst 0.15.1 和中文字体。Linux 使用 `fonts-noto-cjk` 与 `fonts-dejavu-core`；macOS 可使用系统宋体和黑体。字体不同可能导致分页不同，CI 统一使用 Noto CJK。

```bash
uv sync --locked
bash scripts/build-papers.sh
# 只重新排某一年
bash scripts/build-papers.sh --years 2022
uv run python scripts/check_papers.py
```

输出位于 `source/_static/files/papers/`。`make dirhtml` 会先构建全部 PDF，再构建网页。PDF、`build/papers/` 中间数据及生成 CSS 均不提交；GitHub Actions 从源文件生成下载件。

## 编辑资料

- `papers/YYYY.md` 是人工维护的排版来源；每题使用 `## 题号.`，题号必须连续为 1—47。
- `papers/YYYY.typ` 调用共享模板；`exam-template.typ` 负责版式。
- `assets/YYYY/` 保存题目所需插图，Markdown 路径相对于 `typst/`，例如 `assets/2022/example.jpg`。
- 选项统一使用 `A.`、`B.`、`C.`、`D.`；代码使用带语言的围栏，公式使用 `$...$`。
- `papers/manifest.json` 记录版本说明和已知缺项。题号、答案泄漏、选项重复、图片路径和代码围栏由测试检查；这些检查不等同于逐字内容校定。

原始扫描和两批 OCR 结果保留在忽略的 `resources/真题/` 下。第二轮识别使用 PaperBeam 的 PaddleOCR 引擎，识别结果仅用于对照；公式、表格和图片仍以原扫描为准，不能用纯文本 OCR 替换整份试卷。

重新 OCR 是显式操作，不在构建或 CI 中执行。先设置自己选择的服务地址，然后运行：

```bash
uv run python scripts/ocr_papers.py --endpoint "$OCR_ENDPOINT" --years 2022
```

脚本保存任务回执，可再次运行继续下载。`convert_materials.py` 只将原始 OCR 导入 `resources/真题/待校对/`，不会覆盖已编辑的试卷。`--syllabus` 是单独的 macOS 考纲导入功能。
