## 41. **(1) 基本设计思想**

从右向左扫描数组，同时维护当前位置及其右侧元素的最小值 minSuffix 和最大值 maxSuffix。若 A[i] 非负，则与后缀最大值相乘可取得最大乘积；若 A[i] 为负，则与后缀最小值相乘可取得最大乘积。

**(2) 算法**

```c
void calMulMax(int A[], int res[], int n)
{
    if (n <= 0) return;

    int minSuffix = A[n - 1];
    int maxSuffix = A[n - 1];

    for (int i = n - 1; i >= 0; --i) {
        if (A[i] < minSuffix) minSuffix = A[i];
        if (A[i] > maxSuffix) maxSuffix = A[i];

        if (A[i] >= 0)
            res[i] = A[i] * maxSuffix;
        else
            res[i] = A[i] * minSuffix;
    }
}
```

**(3) 复杂度**

时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。

## 47. （1）传播时延、吞吐量与文件传输时间

R1 至 R2 的信号依次经过地面到卫星、卫星到地面两段链路。单向传播时延为

$$t_p=\frac{2\times36000}{300000}=0.24\ \mathrm{s}.$$

卫星链路的数据传输速率为 200 kb/s，是整条路径的瓶颈，因此最大吞吐量为 **200 kb/s**。

传输 4000 B 文件，发送时延为 $4000\times8/200000=0.16\ \mathrm{s}$，最少总时间为

$$t=t_p+t_t=0.24+0.16=0.40\ \mathrm{s}.$$

（2）发送窗口与序号位数

一帧的发送时间为 $t_f=1500\times8/200000=0.06\ \mathrm{s}$，确认往返传播时间为 $2t_p=0.48\ \mathrm{s}$。设发送窗口为 $W$，则

$$U=\min\left(1,\frac{W t_f}{t_f+2t_p}\right)=\min\left(1,\frac{W}{9}\right).$$

由 $U\geq0.8$ 得 $W\geq7.2$，故最小发送窗口为 **8**。GBN 的接收窗口为 1，序号空间须满足 $2^m\geq W+1=9$，故至少需要 **4 位**序号。
