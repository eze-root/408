## 41. （1）算法的基本设计思想

按照在二叉搜索树中查找目标 $k$ 的方法，从根开始沿着某条向下的路径进行查找。若当前结点中的关键字值与 $k$ 相等，则结果只包含一个结点，差值的绝对值为 0，不相等时，结果最多包含两个结点，差值的绝对值大于 0。

对于不相等的情况，若当前结点中的关键字值大于 $k$，则结果只可能是当前结点或/及左子树中的结点，此时沿 left 指针继续查找。若当前结点中的关键字值小于 $k$，则结果只可能是当前结点或/及右子树中的结点，此时沿 right 指针继续查找。直到遇到空指针时为止。

（2）算法实现

```c
#include <limits.h>
#include <stdio.h>

void searchX(BTree root, int k)
{
    BTree p = root, first = NULL, second = NULL;
    long long best = LLONG_MAX;

    while (p != NULL) {
        long long delta = (long long)p->data - k;
        long long dist = delta < 0 ? -delta : delta;
        if (dist < best) {
            best = dist;
            first = p;
            second = NULL;
        } else if (dist == best) {
            second = p;
        }
        if (delta == 0) break;
        p = delta > 0 ? p->left : p->right;
    }
    if (first == NULL) return;
    printf("最小差值绝对值 = %lld\n", best);
    printf("结点 = %d\n", first->data);
    if (second != NULL) printf("结点 = %d\n", second->data);
}
```

每次比较后只沿一个子树继续查找，访问结点数不超过树高 $h$，时间复杂度为 $O(h)$，辅助空间复杂度为 $O(1)$。

## 45. （1）时钟中断发生了 22 次，CPU 调度发生了 7 次。第一次执行 P1、P3、P4 的时刻分别是 90 ms、140 ms、20 ms。

CPU 执行时间线如下。

| 时间区间 / ms | 运行进程 | 本段结束原因 |
| --- | --- | --- |
| 10—20 | P2 | 被高优先权 P4 抢占 |
| 20—70 | P4 | 时间片用完，优先权降为 4 |
| 70—80 | P2 | 执行完成 |
| 80—90 | P4 | 执行完成 |

（2）时间片增至 100 ms，因时间片用完而触发的调度减少，CPU 调度次数减少。中断间隔改为 1 ms 后，时钟中断频率升高，系统处理中断的开销增加。
