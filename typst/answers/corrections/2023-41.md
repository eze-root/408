## 41.（13 分）K 顶点

逐个考察顶点 v：邻接矩阵第 v 行的和是出度，第 v 列的和是入度。出度大于入度时，输出该顶点并累加计数。

```c
int printVertices(MGraph G) {
    int count = 0;
    for (int v = 0; v < G.numVertices; ++v) {
        int outDegree = 0, inDegree = 0;
        for (int u = 0; u < G.numVertices; ++u) {
            outDegree += (G.Edge[v][u] == 1);
            inDegree += (G.Edge[u][v] == 1);
        }
        if (outDegree > inDegree) {
            printf("%c ", G.VerticesList[v]);
            ++count;
        }
    }
    return count;
}
```

时间复杂度为 $O(n^2)$，辅助空间复杂度为 $O(1)$。
