每完成一套真题，复制下面的结构记录一次。复盘重点是找到下一步动作，而不是写长篇总结。

## 基本记录

| 数据结构 | ____ / 45 |
| 计算机组成原理 | ____ / 45 |
| 操作系统 | ____ / 35 |
| 计算机网络 | ____ / 25 |

## 错题归因

- [ ] 知识点未掌握
- [ ] 概念混淆
- [ ] 计算或编码失误
- [ ] 审题遗漏条件
- [ ] 时间分配不合理
- [ ] 蒙对但无法解释

## 下一步

只写 1—3 个可执行动作，例如“重做 Cache 地址划分专题 10 题”，不要写“加强基础”这类无法检查的目标。
