## 章节内容

1. 概述与体系结构：协议、接口、服务，OSI 与 TCP/IP 模型，网络分类和性能指标；
2. 物理层：码元、波特、速率，奈奎斯特和香农定理，编码与调制，三类交换方式、数据报与虚电路，传输介质、中继器和集线器；
3. 数据链路层：组帧、检错和纠错，停止等待、GBN、SR，信道划分、随机访问和轮询，以太网、无线局域网、VLAN、PPP 与交换机；
4. 网络层：路由与转发、SDN，IPv4、NAT、CIDR，ARP、DHCP、ICMP，IPv6，RIP、OSPF、BGP，IP 组播、移动 IP 与路由器；
5. 传输层：端口，UDP 数据报与校验和，TCP 报文段、连接管理、可靠传输、流量控制和拥塞控制；
6. 应用层：C/S 与 P2P，DNS 解析，FTP 的控制连接和数据连接，邮件格式、MIME、SMTP、POP3，WWW 与 HTTP。

## 练习重点

- 计算发送时延、传播时延和吞吐量；
- 划分子网并分析路由表；
- 按报文顺序记录 TCP 序号、确认号、接收窗口和拥塞窗口；
- 画出网页访问中 DNS 查询、TCP 建连和 HTTP 请求的先后顺序。
