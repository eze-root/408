# 计算机组成原理


## 章节内容

1. 数据表示与运算：进制、定点数、浮点数、补码和运算器；
2. 存储系统：主存、Cache、虚拟存储器与地址映射；
3. 指令系统：指令格式、寻址方式与程序执行；
4. CPU：数据通路、控制器、指令周期与流水线；
5. 总线与 I/O：中断、DMA 和设备控制。

## 练习重点

- 位级表示与边界值计算；
- Cache 命中、地址划分和平均访问时间；
- 指令执行过程与数据通路分析；
- 流水线性能、冒险与加速比计算。

:::{admonition} 学习提醒
:class: note
分析一条指令时，依次写出取指、译码、取操作数和执行过程，并标出使用的寄存器及访问存储器的步骤。
:::
