# 专项训练

```{article-info}
:avatar-outline: muted
:author: 408 学习小组 updated on

:class-container: sd-p-2 sd-outline-muted sd-rounded-1
```

专项训练放在知识学习和整套真题之间：题量不用贪多，但必须让同类题的解题步骤稳定下来。

::::{grid} 1 2 2 3
:gutter: 2

:::{grid-item-card} 选择题
概念辨析、算法过程和快速计算。训练识别考点、排除干扰项与控制单题耗时。
:::

:::{grid-item-card} 计算题
Cache、流水线、调度、分页、子网与 TCP。统一书写已知量、公式、单位和结论。
:::

:::{grid-item-card} 综合与算法题
先拆小问、画结构或过程图，再写步骤。算法题先保证思路与边界，再追求简洁。
:::
