# 专项训练

学完一个章节后，可以先做同类题，再做整套试卷。本页介绍三类题的练习方法，题目可从教材、习题册或历年真题中选取。

::::{grid} 1 2 2 3
:gutter: 2

:::{grid-item-card} 选择题
辨析概念、推演算法、完成短计算。订正时说明每个错误选项错在哪里。
:::

:::{grid-item-card} 计算题
常见题型包括 Cache、流水线、调度、分页、子网与 TCP。写清已知量、公式、单位和结果。
:::

:::{grid-item-card} 综合与算法题
先逐项列出题目要求，再写解题过程。算法题需要说明思路、边界情况和时间复杂度。
:::
