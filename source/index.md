## 四科复习提纲

::::{grid} 1 2 2 2
:gutter: 2

:::{grid-item-card} 01 · 数据结构
:link: lectures/data-structures
:link-type: doc
:class-card: subject-card subject-ds

线性表、树、图、查找和排序。练习算法过程、复杂度分析与代码阅读。

**45 分 · 建议 55 分钟**
:::

:::{grid-item-card} 02 · 计算机组成原理
:link: lectures/computer-organization
:link-type: doc
:class-card: subject-card subject-co

数据表示、存储系统、指令系统、CPU、总线与 I/O。练习地址划分、指令执行和流水线计算。

**45 分 · 建议 55 分钟**
:::

:::{grid-item-card} 03 · 操作系统
:link: lectures/operating-systems
:link-type: doc
:class-card: subject-card subject-os

进程与线程、同步互斥、内存、文件和 I/O。练习信号量、调度、地址转换和页面置换。

**35 分 · 建议 40 分钟**
:::

:::{grid-item-card} 04 · 计算机网络
:link: lectures/computer-networks
:link-type: doc
:class-card: subject-card subject-cn

网络分层、可靠传输、路由与应用层协议。练习子网划分、时延计算和 TCP 窗口变化。

**25 分 · 建议 30 分钟**
:::
::::

## 按复习进度使用

::::{grid} 1 2 2 3
:gutter: 2

:::{grid-item-card} ① 按章复习
:link: lectures/index
:link-type: doc
:class-card: action-card

查看各科章节和练习重点，对照考纲标出尚未学过的内容。
:::

:::{grid-item-card} ② 按题型练习
:link: labs/index
:link-type: doc
:class-card: action-card

选择题、计算题和算法题分别练习。订正时记下错误步骤和遗漏条件。
:::

:::{grid-item-card} ③ 限时做套卷
:link: assignments/index
:link-type: doc
:class-card: action-card

留出 180 分钟独立作答。评分后整理错题，隔一周再做一次。
:::
::::

:::{admonition} 使用建议
:class: tip
还没学完四科时，可以按章节找题练习。准备模拟时，选一套没做过的卷子计时完成，保留作答和订正记录。
:::
